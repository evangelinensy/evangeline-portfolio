# Sounds Directory

This directory contains audio files for the portfolio website.

## Required Files

### click.mp3
A click sound effect that plays when users click on the CD disc project cards.

**Requirements:**
- Format: MP3
- Suggested duration: 100-300ms
- Volume: Medium (will be played at 50% volume)
- Type: Short click or tap sound

**Where to find:**
You can find free click sound effects from:
- [Freesound.org](https://freesound.org)
- [Zapsplat.com](https://zapsplat.com)
- [Mixkit.co](https://mixkit.co/free-sound-effects/)

**Usage:**
Once added, the sound will automatically play when users click on any CD disc project card in the portfolio.
